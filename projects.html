Speed Demon 2026: four performance rewrites in 72 hours

Nov 2026 · Solo · C++20 · Code and optimization logs

  • 3rd Track D leaderboard
  • ~850× Track D vs. reference
  • 4/4 tracks entered
  • A 72-hour championship where every entrant gets the same task, the same data and the same scoring machine (Intel i5-13500, 12 threads, 8 GB cap). Output must match the reference byte for byte; the score rewards wall time, peak memory and short code.
  • Track D, graph traversal (3rd place): 2,000 shortest-path queries on a road network with 1.74M nodes and 5M edges, from 72.69 s and 893 MB down to 0.085 s and 57 MB. I contracted pass-through chains, renumbered nodes with locality-preserving BFS so nearby roads sit together in memory, and used a bidirectional Dijkstra with a bucket queue.
  • Tracks A–C: AVX2 SIMD parsing, carry-less-multiply quote masks for CSV, AES-NI hashing, lock-free shared hash tables and branch-free percentile selection.
  • Every version checked against the reference output (sha256) and run under AddressSanitizer, UBSan and ThreadSanitizer.

5G O-RU PHY testbed on Zynq-7000

2021–2024 · C-DOT, Senior Engineer

  • 245.76 Mbps IQ stream
  • 1.6M+ packets, zero drops
  • 30.72 MB/s deterministic FPGA–ARM transfer
  • Built and integrated a 5G open radio unit (O-RU) PHY testbed on Zynq-7000 FPGA/ARM with Intel FlexRAN, supporting end-to-end 5G NR system validation.
  • Debugged spectral regrowth and PHY signal-quality degradation by correlating FPGA ILA captures with MATLAB reference models; isolated a fixed-point truncation in the signal-processing chain.
  • Root-caused packet loss under a 245.76 Mbps IQ stream to lwIP buffer exhaustion; reworked buffering to carry 1.6M+ packets with zero drops.
  • Implemented deterministic FPGA–ARM data movement with shared-memory ping-pong buffers and AXI DMA, sustaining 30.72 MB/s.
